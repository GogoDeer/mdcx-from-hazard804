# 模式与刮削策略

四种工作模式、网站配置方式与字段优先级——决定"刮什么、从哪刮、怎么取舍"。

## 四种刮削模式（设置 → 刮削模式）

| 模式 | 做什么 | 适合 |
|---|---|---|
| **正常模式** | 完整流程：扫描 → 刮数据 → 下图片 → 生成 NFO → 重命名 → 移动 | 新下载的视频 |
| **视频模式**（整理模式） | 只刮番号用于命名，重命名并移动视频；**不下图、不生成 NFO** | 不想做海报墙，只按番号归类文件 |
| **更新模式** | 重新整理已有 NFO 的文件结构，按新命名规则移动 | 刮过但想调整目录结构 |
| **读取模式** | 四个独立开关自由组合（见下） | 维护已有媒体库 |

**读取模式**是唯一不受断点续刮缓存干扰的模式（始终处理全部选中文件）：

| 子选项 | 作用 |
|---|---|
| 有 NFO 时更新 | 按更新模式规则整理已有文件 |
| 无 NFO 时刮削 | 对没有 NFO 的文件联网重刮 |
| 重新下载 | 重新下载图片 |
| 更新 NFO | 更新 NFO 内容（如补演员 TMDB ID） |

典型用法——**改命名规则后整理存量库**：改好命名模板 → 选读取模式 → 勾「有 NFO 时更新」→ 开始。

## 网站配置

### 网站偏好（三选一）

| 偏好 | 行为 |
|---|---|
| 字段优先（info） | 各站都刮，按字段优先级合并出最优结果 |
| 速度优先（speed） | 优先返回快的站点，求快 |
| 指定网站（single） | 只用你指定的单一站点 |

### 按类型配置默认源（设置 → 刮削网站）

有码 / 无码 / 素人 / FC2 各类型的默认网站源列表可**拖拽排序**，排前面的优先。增删站点、看各站覆盖范围见 [[支持站点与图源]]。

### 字段优先级（19 项）

多站点结果按字段合并：例如标题取 A 站、简介取 B 站。每个字段可独立拖拽来源顺序；每个字段行还可勾选 **「跳过」**——该字段完全不抓取、保留 NFO 既有值，适合手动维护的字段。可**按刮削类型（有码/无码等）分别设置**。

常见调优：
- **剧照频繁 404** → 把更稳的来源（JavDB、DMM）排前（FAQ #10）
- **封面带水印** → JavDB App 系（无水印 CDN）/ DMM 高清排前（[[图片下载的封面优化|图片与封面]]）

## NFO 合并策略

重刮时如何处理已存在的 NFO（读取模式区域下拉，5 选 1）：

1. 新数据优先（覆盖）
2. 本地 NFO 优先
3. 合并数组（标签等去重合并）
4. 保留已有（只补新增字段）
5. 仅填空字段

手动改过的简介/标签怕被覆盖时，选 4 或 5。

## 多配置文件

设置页底部「当前配置 / 另存为 / 恢复默认 / 保存」：可为不同媒体库（如"有码库""欧美库"）保存多份配置随时切换，各配各的站点源、命名与类型偏好。
