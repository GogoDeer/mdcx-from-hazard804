# 安装与运行

各平台的获取、运行与升级方式。想直接上手刮削请先看 [[新手三分钟上手]]。

## 下载哪个包

打开 [Releases 页](https://github.com/cdlongbow/mdcx-diy/releases)，最新 release 的文件命名为 `MDCx-<版本>-<平台>-<架构>-<提交号>.<后缀>`：

| 平台 | 文件 | 运行方式 |
|---|---|---|
| Windows 10/11 (x64) | `...-windows-x86_64-....exe` | 双击运行，绿色免安装 |
| macOS (Apple 芯片) | `...-macos-aarch64-....dmg` | 拖入 Applications |
| macOS (Intel) | `...-macos-x86_64-....dmg` | 拖入 Applications |
| Linux (x86_64) | `...-linux-x86_64-...`（无后缀） | 终端执行 `chmod +x 文件名` 后 `./文件名` |

- 软件内「检查最新版本」就是对照 Releases 的数字版本标签，无需手动比对文件名。
- 首次运行被系统安全提示拦截时（macOS Gatekeeper / Windows SmartScreen），按提示确认来源即可；本程序免安装、无后台服务、不联网自启。

## 数据存放位置

- **配置文件**：程序目录下的 `MDCx.config` 记录了当前使用的 JSON 配置文件路径；旧版 INI 配置启动时自动迁移，已删除站点的残留旧值自动清理。
- **用户数据**：配置文件同目录的 `userdata/`（演员数据库 `actor_database.xlsx`、Amazon ASIN 缓存、刮削进度库、演员图片缓存、超分工具等）。**迁移/备份搬这一个目录即可**。
- 多个配置文件可通过设置页底部「当前配置 / 另存为 / 恢复默认」切换管理。

## 从源码运行

需要 Python ≥ 3.13 与 [uv](https://docs.astral.sh/uv/)：

```bash
git clone https://github.com/cdlongbow/mdcx-diy.git
cd mdcx-diy
uv sync --locked --all-extras --dev
uv run python main.py
```

Linux 桌面环境若提示缺少 Qt 运行库：

```bash
sudo apt install libxcb-xinerama0 libxcb-cursor0 libxcb-icccm4 libxcb-image0
```

花屏/无法启动时可尝试 `export QT_QPA_PLATFORM=xcb`。

## 升级与回退

- 直接下载新版程序覆盖即可，`userdata/` 与配置文件原样复用；
- 配置项随版本自动迁移，升级后旧配置照常可用；
- 大版本改动会写进 [更新日志](https://github.com/cdlongbow/mdcx-diy/blob/main/docs/changelog.md) 与每次 Release 正文；
- 出问题想回退：换回旧版 exe/dmg，配置向下不保证兼容，建议大升级前备份 `userdata/` 与配置文件。

## 界面大小不合适

「软件设置 → 高级 → 高分屏缩放」提供 8 档：跟随系统 / 80% / 90% / 100% / 125% / 150% / 175% / 200%，保存后重启生效。窗口本身会依据屏幕可用区自适应启动尺寸与最小尺寸，小屏/高分缩放环境自动收窄。
