# Emby 集成与演员管理

NFO 兼容 Emby / Jellyfin / Kodi；内置演员管理器批量同步头像与简介；演员库维护工具离线整理 `actor_database.xlsx`。

## NFO 与媒体库对接

- 勾选「下载 NFO」后，媒体库指向**刮削目录**即可被 Emby/Jellyfin 识别。
- NFO 含 30+ 字段：番号/标题/原名/简介、发行日期/年份/国家、演员（多语言名+TMDB ID）、导演、标签/系列/片商、三类图 URL、预告片 URL、各站外部 ID、公众/影评人评分。
- 演员头像同步生成 Kodi 兼容 NFO 与图片。
- 重复刮削防覆盖：重刮时选 NFO 合并策略「保留已有 / 仅填空字段」保护手动整理内容（[[模式与刮削策略]]）。
- NFO 在 Emby 不显示：先确认勾了「下载 NFO」，再在 Emby 媒体库设置里勾选「读取 NFO」类选项。

## 演员管理器（左侧导航「演员管理」）

Emby/Jellyfin 中演员缺头像/简介时的批量补全工具：

1. 填写 Emby 地址与 API 密钥，点「连接 Emby」。**API 密钥在 Emby 管理后台 → 高级 → API 密钥生成**。
2. 「获取演员列表」，选择媒体库。
3. 选获取模式：**缺失头像或缺失简介**（默认）/ 仅缺失简介 / 仅缺失头像 / 头像和简介都缺 / 重新获取所有演员详情 / 重新获取简介、头像或两者。
4. 点「根据设定获取数据」（再点可取消）——头像按 **Gfriends / graphis.ne.jp / minnano-av / 本地文件夹** 优先级匹配；简介按 **本地演员库 / 维基百科 / minnano-av / 数据库** 匹配。本地库命中且简介存在时跳过网络来源。
5. 表格绿色行=有更新项。点「开始全部更新同步」写入 Emby（完成后自动刷新列表）。
6. **■ 设置**：数据源优先级、演员类型过滤/去重、本地头像目录、Bypass 落地域名白名单。 **■ 数据源测试**：输入演员名逐源验证。 **■ 详情**：双击演员行，可编辑简介/信息、单独同步头像或简介。

**常见状况**（FAQ #17/#21/#22）：

- 日志「限流冷却中」：维基站点要求等待，软件自动退避，属正常；
- 「跳过 N 个不在所选库影片中出演(Actor)的人员」：预期行为（导演/编剧/配音被剔除）；
- 关闭演员管理器主程序退出：确认已升级到含修复的 v2.1.1+。

下载头像缓存在 `userdata/emby_actor_cache/`，「清空缓存文件夹」可清理。入口可在「软件设置 → 高级 → 隐藏入口」隐藏（FAQ #6）。

## 演员库（userdata/actor_database.xlsx）

9 列：日文原名 / 中文名 / 繁体名 / 别名 / 链接 / tmdbid / tmdb url / 出生日期 / 简介。刮削后 TMDB API 自动补全 ID 与多语言名。**备份迁移搬整个 userdata 目录即可**。

## 演员库维护工具（「软件工具」页，直接操作 xlsx）

| 按钮 | 用途 |
|---|---|
| 补全中文名 | 按已有 TMDB ID 补中/英/繁译名 |
| 补全 LibreDMM 链接 | 补演员信息页链接 |
| 补全别名 | 来源可选 TMDB / minnano-av / JavDB；默认只补缺别名行，可全量更新 |
| JavDB 中文名 | JavDB 移动端 API 补中文/繁体名，免 TMDB Key |
| minnano 补全 | 补生日/简介，日文自动翻译 |
| 检查用户库 | 扫描格式/数据异常，安全项一键修复 |
| 剔除男演员 | 按 TMDB gender 删男优（删前备份「男优备份」sheet） |
| 校验 tmdbid 有效性 | 清除失效 id 并按姓名重搜 |
| 更新 nfo tmdbid | 本地库新 id 覆盖 NFO 里旧 id |
| 打开演员数据库 | 系统默认程序打开 xlsx 手工编辑 |

**分片续跑**：联网维护任务默认单次限量 5000 行，20000+ 行可多次运行逐片处理；「起始行/结束行」可手动分段，中断后日志提示「将起始行填入 N-1 即可续跑」——照填即可断点续传。滑动窗口并发（TMDB 5 / LibreDMM 2 / JavDB 5）；独立「停止当前维护任务」按钮，停止时保存已完成部分。
