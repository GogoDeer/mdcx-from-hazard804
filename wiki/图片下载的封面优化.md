# 图片下载的封面优化

海报、缩略图、背景图、剧照的下载开关，与一系列"让海报墙更好看"的优化链路。

## 下载范围（设置 → 下载）

| 内容 | 开关 |
|---|---|
| 海报 poster / 缩略图 poster_small / 背景图 fanart | 默认下载 |
| 额外剧照 | 可设下载数量；来源按「剧照」字段优先级回退 |
| 预告片 / Extras 预告片 | 「下载预告片」「下载 Extras 预告片」 |
| 预览视频 preview | 「下载预览视频」 |
| NFO | NFO Tab 逐项配置 |

所有图片下载统一 50MB 上限，防异常大文件。个别剧照源 404 时按来源优先级自动换站重试（FAQ #10）；勾选「图片下载失败时，不视为失败！」避免整条记录标红。

## 高清图源链（自动生效）

多站刮削时软件自动把封面升级到高清图，按番号/来源依次尝试：

1. **DMM 官方高清直链**：十个主流爬虫（LibreDMM / R18.dev / JavBus / JavDB 系 / DMM 系 / JavLibrary / avbase）返回的低清自动替换为 DMM awsimgsrc 高清图（竖版 `ps` 通常 1032×1469）；内置约 110 个主流系列前缀表，并自动学习未收录系列的前缀（学习数据在 `userdata/dmm_prefix_learned.json`）。
2. **JavDB 无水印原图**：JavDB / JavDB API / JavDB App 三源的图床图片自动改走 JavDB App 专用 CDN（无水印、透明解密），替代带水印的网页版图。
3. **Poster 选优**（poster_auto_best，默认开）：候选池注入 DMM 竖版高清候选，按尺寸自动胜过低清原图。

**官方图源兜底**（所有图源站点都拿不到图时，默认开，可在下载「下载高清图」组关闭）：

- **DMM**：按番号直构官方 CDN 高清封面；无码番号（FC2/HEYZO 等）不命中。
- **MGStage**：DMM 不收录的素人番号（LUXU/OTIM/CHUC/GERK/ONEZ/ONEX/MFC/ARA 系列）直构 MGStage 官方 CDN——横版大图作封面、竖版图作海报。

## Amazon 高清封面

从日亚搜 1500px 高清封面：EAN-13 条码 → ASIN 三层搜索策略，ASIN 映射缓存于 Excel 库（随版本更新自动合并，不覆盖你手填的值）。已是 DMM 高清（宽≥700）时直接放行，不浪费时间搜日亚。

## 人脸裁剪

内置 OpenCV 人脸检测模型，自动定位海报人脸并裁成 **2:3** 标准海报比例。「软件工具」页另有**图形化海报裁剪工具**（拖拽选区）与**封面补图工具**（按番号批量补缺失封面/缩略图，复用当前站点优先级/命名/裁切/水印规则，同样走 DMM 直链兜底）。

## 水印徽标（设置 → 水印）

图源自带水印可叠加**图标徽标**标记内容属性：**字幕 / 有码 / 无码 / 破解 / 流出 / 高清 4K·8K** 六类。可配置：作用图片类型（海报/缩略图/背景图分别开关）、大小档位（按图片高度比例）、添加规则（自动轮转 / 固定角落 / 按类型分角落）。

> 想减少"图源原生水印"：在字段优先级里把 JavDB App 系（无水印 CDN）与 DMM 高清排前（[[模式与刮削策略]]）。

## 海报超分（实验性）

对最终落盘海报做 AI 超分补清（Real-ESRGAN 4x / waifu2x 2x 两档预设），**仅当海报最长边低于阈值（默认 800px）时触发**：

- 工具为官方预编译 ncnn-vulkan 二进制，需支持 Vulkan 的 GPU（Intel 集显第 6 代酷睿起）；
- Windows/Linux 打包版内置工具，macOS 打包版与源码运行首次使用从 GitHub Release 下载一次；
- 下载按内置 sha256 基准校验；无 Vulkan、下载失败、超时一律静默保持原图，不影响刮削结果。

### 存量库补超分（给已刮削下载的图片补清）

超分作用在刮削收尾时的**最终落盘海报文件**上，与图片是新下载还是早已存在无关——正常刮削和读取模式都走这条收尾链路，保留旧海报（不勾选覆盖）也不会重复下载，只原地补超分替换。

给已刮过的媒体库批量补超分的操作步骤：

1. 软件设置 → 下载 → 下载高清图组，确认「海报超分」开关开启（默认开）；
2. 用**读取模式**：它不受断点续刮缓存影响，每次都会处理全部选中文件——正常模式下"已完成且未变化"的文件会被整体跳过，根本走不到超分这一步；（替代做法：软件工具 →「刮削缓存管理」清空缓存后用正常模式重刮）
3. 选中目标目录，点开始，等待完成；日志出现「✨ 海报超分完成」即某张海报被处理；
4. 完成后核对几张原低清封面确认效果（超分产物必须先通过尺寸校验才会替换原图，任何失败保持原图）。

注意与边界：

- **只有海报会被超分**，缩略图、背景图、剧照、额外剧照都不处理；
- 尺寸门槛：仅最长边低于阈值（默认 800px）的海报触发，高清图不会被反复放大；想连中等清晰度一起提升，改配置文件 `poster_sr_max_dim`（如 1000），代价是批量耗时长、文件体积增大；
- 软件工具页的「封面补图」同样会走超分：新补齐的低清海报在加水印前自动增强（同开关同阈值），无需额外操作；
- 相关配置项（配置文件 json 直接编辑）：`poster_sr_enabled` / `poster_sr_preset`（realesr-photo-4x / waifu-photo-2x）/ `poster_sr_max_dim`。
