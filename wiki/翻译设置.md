# 翻译设置

标题/简介/标签的自动中文化。入口：「软件设置 → 翻译」。

## 六个翻译引擎

| 引擎 | 需要配置 | 说明 |
|---|---|---|
| Google | 不需要 | 免费，自动爬取接口 |
| Bing | 不需要 | 免费，国内网络友好 |
| 百度 | API Key | 百度翻译开放平台申请 |
| DeepL | API Key | DeepL 官网申请 |
| DeepLX | 自建 URL | 自建 DeepL 免费代理 |
| LLM（大模型） | API Key + Base URL | 可自定义 Prompt，术语最准 |

- **多引擎降级**：引擎可排顺序，第一个失败自动换下一个。
- **LLM 翻译**：支持 OpenAI 兼容接口，自定义 System Prompt 统一术语风格；同批文本（系列片/失败重刮）带缓存，重试不重复花 token。

## 翻译范围

- 可勾选**哪些字段**参与翻译：标题、简介、标签等。
- 目标语言在设置中选择（简体中文 / 繁体中文等）。
- 翻译发生在图片/NFO 落盘前，命名模板里的"标题"即译名；原始日文名保留在"原标题"字段。

## 常见问题（FAQ #16）

- 翻译超时/失败：确认 API Key 有效、账户有余额；
- 网络代理需放行翻译 API 域名（LLM 服务商国内多需代理，见 [[网络与代理设置]]）；
- 系列片重刮成本低：同文本命中缓存直接复用。
