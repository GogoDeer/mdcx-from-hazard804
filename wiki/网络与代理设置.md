# 网络与代理设置

代理分流、Cloudflare 绕过、限流与自动冷却。入口：「软件设置 → 网络」。

## 代理分流（默认方案）

1. 本机先运行代理软件（Clash/v2ray 等），记下 HTTP 端口；
2. 「代理地址」填如 `http://127.0.0.1:7890` —— 支持**任意** HTTP/HTTPS/SOCKS5 地址：本地、局域网 `http://192.168.1.100:7890`、远程服务器均可（议题 #70）；
3. 「走代理网站」列表里的域名走代理，其余全部直连。默认已覆盖 javbus/javdb/missav/amazon.co.jp 等 **34 个域名**（完整列表见设置页内）。

**两种写法**（议题 #83）：

| 写法 | 效果 |
|---|---|
| 填域名 | `javbus.com` 只对该域名生效 |
| 填数据源名 | 从输入框旁**下拉框**选 missav / javdb / 7mmtv 等，该站主域+镜像+备用域名**全部**自动走代理，站点换域名不用改配置 |

「直连白名单」可把指定域名强制排除出代理。

## Cloudflare 绕过

站点返回 CF 防护页时，软件调用**外部 CF 服务**自动取回真实页面，本体无内置浏览器：

- **TRAWL**（推荐）：到仓库 Releases 下载 `trawl-portable-*` 便携包，解压双击 `start-trawl.bat`，「软件设置 → 网络 → CF Bypass 服务地址」填 `http://127.0.0.1:8191`（只填主机端口，**不要**附带 `/v1` 路径——协议适配层自动识别 TRAWL `/scrape` 或 FlareSolverr `/v1`）。便携版报 `Cannot find package 'elysia'` 见 FAQ #19。
- **FlareSolverr**：传统 Docker 方案同样支持。
- 可为 Bypass 服务配置**独立代理**；服务失效时自动跳过，不空等。
- **落地域名白名单**：填可信落地域名（逗号分隔，支持 `*.example.com`），校验 Bypass 返回的最终域名，防第三方服务被劫持；留空放行。
- **Selenium 绕过（仅 JavLibrary）**：JavLibrary 遇 CF JS 挑战时自动 fallback 到 Selenium+Edge 无头浏览器（本机需 Windows 10/11 + Edge，首次自动装 selenium；无 Edge 优雅降级，连续失败 3 次冷却 5 分钟）。

## 限流、指纹与自动冷却

- **请求指纹**：curl-cffi 模拟浏览器 TLS，默认 7 种浏览器画像自动轮换，配完整 sec-ch-ua 请求头。
- **限速**：并发数与全局线程延时控制节奏；维基系双桶限速（5/秒突发 + 180/分钟滚动）。
- **Retry-After 自动冷却**（最新版新增）：站点返回 429/503 并附带等待要求时，软件自动暂停对该站的新请求直到指定时刻（上限 5 分钟），日志出现**「限流冷却中」**属预期行为，无需干预。
- 重试：HTTP 失败自动重试（默认 3 次）；检测网络页刮削探测超时自动 30s/45s/60s 三次递进。
- **限流不误伤登录态**（v2.1.1 起）：站点返回 429/403/5xx 时只更换浏览器指纹再试，连接与 Cookie 保持不变——被限速的时刻不会顺手丢掉 Cloudflare 通行证或站方登录会话，重试无需重新过人机验证。

## Cookie / Token（设置 → 网络 → Cookie 设置）

| 站点 | 需求 |
|---|---|
| JavDb 网页版 | 搜 FC2 需粘贴浏览器 Cookie；或改免 Cookie 的 javdb_app / javdb_api（FAQ #15） |
| TMDB | 演员 ID 补全需免费 API Key |
| LLM 翻译 / 百度 / DeepL | 相应 API Key |

## 检测网络页

代理/CF 配置改完，到「检测网络」页全量检测或单站复测验证；红的含义速查表见 FAQ #3，启动自检为何只测 5 项见 FAQ #12。
