# 命名与目录整理

用模板变量自定义文件夹/文件/NFO 标题命名，以及存量媒体库的重新整理。

## 三种命名目标（设置 → 命名）

| 目标 | 示例 |
|---|---|
| 文件夹命名 | `[ABP-123] 标题` |
| 文件命名 | `ABP-123.标题.mp4` |
| NFO 标题 | Emby 中展示的标题（可区别于本地文件夹名） |

命名模板使用 Jinja2 模板引擎，支持条件渲染。**完整变量列表见「设置 → 命名」页内提示**，常用变量：

| 变量 | 值 |
|---|---|
| 番号 / 番号字母前缀 | `SSIS-742` / `SSIS` |
| 标题 / 原标题 | 中文译名 / 日文原名 |
| 演员（当前名 / 第一名 / 全部） | 中文译名或原名可配 |
| 系列 / 制作商 / 厂牌 / 发行商 | 合并结果中的对应字段 |
| 发行日期 / 发行年份 | `2024-01-01` / `2024` |
| 片长 / 评分 / 想看数 | 站点返回值 |
| 有码/无码标识 / 4K 标识 / 清晰度 | 标记类字段，可用于条件命名 |
| 中文字幕标识 / 无码流出标识 | 标记类字段 |
| 简介 / 导演 | 长字段慎用 |
| 原文件名 | 整理场景做溯源用 |

## 同系列必定归同一文件夹

模板里构成路径一级的字段（series、actor 等）采用**稳定预算截断**：同一系列名无论刮哪部片都截成同一个目录名，同系列影片必定归到同一文件夹，不会因同批次其它字段长短不同而"差一个字符分家"（议题 #95，2026-09-12 修复）。极长系列名会比旧版多截几个字符，属预期代价。

## 目录结构示例

默认刮削输出结构：

```
刮削目录/
└── 演员名/
    └── 番号 标题/
        ├── poster.jpg
        ├── fanart.jpg
        └── ABP-123.nfo
```

自定义后也可做成 `[厂牌]/番号/` 等任意层级（模板里变量间用 `/` 分隔即成多级目录）。

## 存量库整理：换命名规则不重刮

做好一批刮削想改目录结构：

1. 「设置 → 命名」改好新模板；
2. 选**读取模式**，勾选「有 NFO 时更新」（按更新模式规则整理）；
3. 点开始——读取已有 NFO，按新规则重命名移动，**不联网重刮**。

只刮视频归类（不要图/NFO）用**视频模式**（整理模式）。详见 [[模式与刮削策略]]。

## 文件移动

刮削成功/失败可分别配置移动目标：成功后移动到媒体库目录、失败后移动到待观察目录（刮削模式页），避免失败文件混进成品库。
