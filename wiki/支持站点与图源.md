## 稳定优先的免 CF 通道

**javdb_api、javdb_app、missav_api、r18dev、thejavdb_api** 五条不走 Cloudflare 防护页，直连稳定，建议排到默认源前列。

## 特殊要求站点

| 站点 | 要求 | 处理 |
|---|---|---|
| JavDb（网页版） | 搜 FC2 内容需登录 Cookie | 设置 → 网络 → Cookie 设置粘贴；或改用 javdb_app / javdb_api 免 Cookie |
| dmm、mgstage、prestige、r18.dev、xcity 等日本官网 | 部分对海外 IP 限速/限定 | 站点列表有「日本IP限定」标注，检测页红时换日本节点 |
| javdb | 日本 IP 可能反而受限 | 检测页对应标注 |
| 遇 Cloudflare 防护页的站点 | 需绕过或走代理 | 见 [[网络与代理设置]] 的 CF 绕过 |

## 网络检测页

左侧导航「检测网络」：

- 「开始检测」全量检测，结果按 **基础环境 / 连通性 / 刮削站点 / 账号 API / 辅助服务** 分组；绿点=刮削正常，黄点=可达但异常（悬停看原因）。
- 镜像/动态域名站点会**主站+镜像多地址检测**；API 类爬虫走真实刮削探测。
- 支持输入**任意番号单站测试**（判断"番号不存在"还是"站点挂了"）。
- 探测超时自动递进重试（30s/45s/60s 三次），「重试失败项」按钮改完配置后再验。
- 启动时的自动自检只测 5 项基础连通，全量检测须手动触发（FAQ #12）。

各结果红的含义与处理速查表见 FAQ #3。
